What this tool does — and doesn't do

Decode

Reads the Base64URL-encoded header and payload so you can inspect their JSON contents.

Not verify

Decoding does not prove a token is authentic. This tool does not verify signatures or validate issuer/audience.

Local by design

All decoding happens in your browser. The page makes no API calls and does not upload your token.
